📝 To-Do Web App
SkillCraft Technology – Task 04
A modern, responsive To-Do Web Application that allows users to manage daily tasks efficiently. The app supports adding, editing, deleting, completing tasks, setting date & time, and filtering tasks. All data is stored using Local Storage, so tasks remain saved even after refreshing the page.

⚙️ How the App Works
1️⃣ Adding a Task
Enter a task name
Select date & time
Click Add
Task is saved in localStorage
2️⃣ Marking a Task as Completed
Click the ✔ button
Task gets a strike-through style
Status is updated in localStorage
3️⃣ Editing a Task
Click ✏️ icon
Update the task text
Changes are saved instantly
4️⃣ Deleting a Task
Click 🗑 icon
Task is removed from the list and storage
5️⃣ Filtering Tasks
All → Shows all tasks
Active → Shows incomplete tasks
Completed → Shows finished tasks
💾 Data Storage
This app uses browser Local Storage to store tasks:
Tasks remain saved even after page refresh
No backend or database required
